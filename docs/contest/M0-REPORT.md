## 任务边界与采用的约定

- 目标桌面版本使用 Tauri 2、TypeScript MCP SDK、SQLite 和本机系统密钥链。现行 Python/Qt 发行包继续作为现状与复用代码来源，不冒充新版本。
- 默认角色改为原创；鲸鱼娘“麦香鱼”、ChatGPT 龙娘等第三方形象仅以用户导入包存在，不随参赛源码或发行包提供。
- 最新要求优先：六种逻辑状态都要能反馈，缺对应动作时使用文字气泡；不能因缺素材中断提醒、领券、余额或进度流程。庆祝、工装和小账本动作同样适用该退化规则。
- 交互沿用现有 Agent 会话，保留通用 Skill/MCP 接口，不另买模型、不限定宿主；桌面入口保持宠物、托盘、右键菜单和气泡。设置尽量复用小型气泡交互。
- 按本次任务书加入小型常显进度和余额展示；当前发行版移除的旧状态容器不作为新设计。进度比例与明确成功/失败分别处理，95% 表示接近完成，不能宣称任务已经成功。
- 下单止于订单生成与品牌渠道跳转，不执行支付。定时任务只做提醒/读取；领券、下单等写入要核对范围，未知提交停止自动重发。
- 每个里程碑交验收报告并暂停，用户确认后才进入下一阶段；日期是目标，不意味着自动越过验收。
