# 麦麦搭子宣传片

这支片子介绍当前 Python / Qt 版本：余额有人盯，进度有人陪，干饭有人喊。
成片保存在本机 `dist/promo-final-20261014/McPet-promo-1080p.mp4`，不随源码提交。

## 内容与素材

18 个片段，约 118 秒，1920×1080、30 fps。包含中文配音、轻音乐、文字说明、
可开关的配音字幕和按功能划分的章节。音乐由脚本合成，没有下载音乐素材。
中文语音由本机 Windows 语音生成；菜单、气泡与动作来自现有 Qt 控件。
画面采用奶油色背景、浅蓝点缀，沿用项目既有视觉规格。

| 顺序 | 内容 |
| --- | --- |
| 1–3 | 开场、右键菜单、Skill / MCP 接入说明 |
| 4–6 | 会话状态与上下文、API 余额与订阅额度、本机用量 |
| 7–9 | 饭点与咖啡提醒、优惠券菜单与领取确认、门店与券后价格 |
| 10–11 | 瑞幸菜单、商品、订单预览、查单 / 取餐码、取消确认 |
| 12–13 | 饮食记录与今日营养、设置菜单 |
| 14–17 | 本机角色与皮肤、换装、炸薯条、闲逛与休息 |
| 18 | 结束语与仓库地址 |

## 重新录制

需要现有桌面 Python 依赖、FFmpeg（含 libx264 / AAC）、Windows 中文字体和
`Microsoft Huihui Desktop` 中文语音。不改变应用运行依赖。

```powershell
python scripts/record_promo.py --ffmpeg "<FFmpeg 可执行文件>" --output dist/promo-final-20261014
```

先做短片检查可加 `--seconds 8`，只生成无配音画面。运行完整命令会输出：

- `McPet-promo-1080p.mp4`：成片，含音频、字幕和章节。
- `cover.png`：封面；`scene-*.png`：逐场检查画面。
- `narration.srt`：配音字幕；`timeline.json`：时间轴。
- `capture-review.json`：录制片段、帧数和捕获异常；编码日志留在同目录。

输出路径强制限定在已忽略的 `dist/`。本机皮肤画面不加入参赛仓库。
脚本使用单独演示目录，禁用凭证读取、账号 / 宿主日志读取和网络业务。
不会拍到其他桌面窗口，也不会改动日常桌宠的偏好或台账。

## 验证边界

全片持续标注“桌宠界面录制 · 演示数据”。数值、门店、优惠券、营养与订单状态为
明确的演示数据；现有界面与状态动画实际运行，业务写请求被演示后端拒绝。
所有确认框最终取消，没有领取真实优惠券、创建订单或支付。

这是 Qt 控件录制与功能介绍。该录制没有执行真实宿主会话、真实账号业务、系统托盘、
屏幕贴边或原生前台鼠标验收。显示设置菜单不等于本机系统密钥链已经实现。
周报、Tauri 迁移、原创默认角色等后续参赛改造没有在片中宣称完成。
外部调用可用性以各自验证报告为准；本片不替代 M0 或后续里程碑验收。

首轮短片发生中文字体缺失，保留于本机 `dist/promo-smoke-20261014/`；
录制脚本随后显式加载中文与符号字体，并提高控件文字的输出精度，重新录制成片。
首次字幕合成使尾段提前结束，旧成片与日志保留为 `McPet-promo-initial-shortest.mp4`
与 `mux-initial-shortest.log`；改用明确的全片时长后重新合成，末尾画面已检查。
旧桌面性能 RED 与比赛改造待办继续保留。
