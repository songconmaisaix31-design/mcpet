# McPet v0.1.0 · 鲸鲸到岗 🐳

第一版来啦。DeepSeek 娘默认陪你上班，ChatGPT 娘也在小衣柜里等你；麦麦套装和默认套装随时切换，选好的样子会记住。

- 饭点帮你看看麦当劳的券和价格，咖啡时间给脑袋续杯；买不买、领不领，听你的明确确认。
- 右键小菜单找功能，结果、选择和确认都在宠物气泡里。
- 沿用你正在聊的 Agent：21 个 MCP 工具和可移植 McPet skill，可选 OpenCode / Claude Code 适配，不另开聊天、不新增模型 Key。
- 工作和饭饭的小本本：本机用量、会话、额度/余额、营养记录，以及更自然的提示和中文订单回执。

**怎么召唤**：Windows 下载 `McPet-v0.1.0-windows-x64.zip`，完整解压后双击 `Start-Pet.vbs`。已有 Python 的 Agent 用户可下载 `McPet-v0.1.0-agent.zip`；接入小抄就在包里的 README。
Agent 接入后重新加载项目会话即可。仅复制技能不等于连接 MCP；麦当劳/瑞幸的账号凭证仍需在本机配置，别发到聊天里。

**这版的小边界**：438 项适用回归与解压包运行检查分别记录在仓库首发文档；不代表完整测试全绿。旧桌面 heartbeat、两项素材边界 RED 仍保留；真实账号下单、支付和模型自动选择技能尚待人工验收。Windows 便携包未签名。
提交结果尚未核实时不会自动重发，先到官方订单核对。本机用量不等于厂商额度或账单，Agent 停下来也不等于任务完成。

素材许可证与出处随包保留，授权待澄清的旧开发素材已从该版本源码和发行包移出。McPet 是社区桌宠，不代表品牌官方产品。
