# 宠物菜单与瑞幸

桌面仅显示宠物、右键小菜单和宠物气泡。默认 stdio 服务仍供任意支持 MCP 的宿主调用；桌宠用 `python -m src.main --desktop` 显式启动。双击/托盘激活只恢复宠物并提示操作，不创建大面板或新聊天。

| 右键分组 | 功能 |
|---|---|
| 会话与额度 | 会话进度、本机用量、账号额度/余额 |
| 麦当劳 | 查券、确认领券、实时报价、确认下单、核对撤单 |
| 瑞幸咖啡 | 查门店、选咖啡、调整规格、预览、确认订单、查单/取餐码、核对撤单、官方登录 |
| 营养台账 | 选真实餐品、输入份数、确认记账、今日汇总 |
| 订单付款 | 气泡选择打开/复制已知订单的官方付款链接 |
| 角色与动作 | 切角色、随时切皮肤、炸薯条/换装、停止、闲逛、休息 |
| 设置 | 时间、城市、位置、自动查询偏好、凭证、显式日志来源、提醒开关 |

结果气泡宽 260 个逻辑像素，文字、输入和按钮共用一个无外框的圆角背景；文字区域按内容收缩，长报告使用细滚动条。每次打开新内容从顶部开始；选项分页，输入与确认均在同一气泡。写入确认不自动消失，后台通知不覆盖正在确认的内容。取消/关闭气泡不提交，退出会取消未确认操作。

## 瑞幸接入

来源：[瑞幸 AI 开放平台](https://open01.luckincoffeecdn.com/)、[官方登录入口](https://open.lkcoffee.com/mcp)。2026-10-13 读取公开工具说明。Streamable HTTP 地址 `https://gwmcp.lkcoffee.com/order/user/mcp`，Bearer Token。

1. 右键 → 瑞幸咖啡 → 登录瑞幸开放平台；在官网登录后复制 Token。
2. 右键 → 设置 → 账号凭证 → 瑞幸 Token，本机气泡输入遮蔽；留空保留，清除走单独确认。不会把 Token 返回 Agent 对话。
3. 设置经度、纬度（不自动定位），查门店并选择；所选门店保存供后续咖啡时间查询。
4. 查询商品，按需切换温度/杯型等规格，输入数量并预览。预估商品价格不代替预览的实付价。
5. 右键确认订单，在气泡核对门店、规格、数量和实付，明确确认后重新算价；变化/过期要求重新确认。创建后手动打开付款链接，查单显示取餐码。

官方工具：`queryShopList`、`searchProductForMcp`、`queryProductDetailInfo`、`switchProduct`、`previewOrder`、`createOrder`、`queryOrderDetailInfo`、`cancelOrder`。每次调用按上游实时 JSON Schema 校验。瑞幸金额单位为元，整数 `16` 换算成 `1600` 分后交给既有 OrderGuard。

Agent 内新增四项瑞幸工具，同样先查真实商品、预览、展示摘要、取得明确确认；不接受凭空编造的 SKU。可通过 `mcpet_configure(coffee_time="15:30")` 修改咖啡时间。

## 自动触发

复用 DailySchedule、串行 worker 和既有后台监控，不增加调度器：

- 默认 11:30 饭点：提醒；已有麦当劳凭证时只读查券和报价。
- 默认 15:00 咖啡时间：已有瑞幸凭证及所选门店时，只读查询偏好的咖啡；未配置则提示入口。
- 活跃会话进入待输入/错误状态、已知账号额度用量进入 ≥80%：条件变化时提醒一次；定时采样继续由原监控运行。
- 本次桌宠已创建的瑞幸订单：复用现有 30 秒调度 tick，只读查单，状态变化时显示取餐码；完成/取消/查询失败或一小时后停止。
- 本机高用量、日志明确任务完成：沿用现有气泡与动作。idle/Stop 不算成功。

自动路径不领券、不下单、不撤单、不记账。提醒可关闭，饭点/咖啡时间可随时修改；同一进程当天任务不重复触发。

提交与撤单的未知效果不会自动重试。瑞幸未知结果记录本机审计；重启仍拒绝重复提交。未知提交需要先到官方 App 核对，由人工处理本机未知记录，不能用重新查报价绕过。

## 验证边界

公开服务无凭证 initialize 返回 HTTP 401，认证账号、真实订单和支付为 NOT_RUN。离线协议与业务 fixture、真实 stdio、Qt/QTest、Windows 实际菜单/气泡分别验证；fixture 不能视作真实账号成功。

旧大面板布局/样式断言按本次产品要求替换为菜单/气泡断言。历史提交仍保留；旧 Windows 联合性能要求 `<150ms` 未放宽，本轮仍 RED（385.04ms），不能作为全部动态验收通过。

首次失败与针对性复测日志留在本机 `.tmp-test-data/luckin-menu/`，不提交本机路径、截图原始信息或账号数据。
