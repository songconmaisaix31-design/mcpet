# 麦麦小窝设计稿输入

目标：一个可爱的原生小窝，辅助正在进行的 Agent 会话；不新增聊天输入。Pixso MCP 已 OAuth 成功，实际 tools/list 返回 24 工具，fetch_context/apply_design/code_to_design/take_screenshot/check_layout 均可用，尚缺设计文件 file_key；设计输出尚未创建。

## 视觉规格（C 可先实现，Pixso 输出随后对照）

- 初始窗口建议 700×720 逻辑像素，最小 560×560；页面主体滚动，小屏自动收敛到工作区，DPR1.5 不裁切。顶部标题与导航固定，首页不堆长日志。
- 背景奶油 #FFF8EE，文字深棕 #493D36，辅助文字 #81756B；麦麦色橘 #ED9864/浅底 #FFF0DF，DeepSeek 色蓝 #72AAD7/浅底 #EAF4FB，成功薄荷 #79B69C，警示深橙 #AD6D39，错误 #AE5962。不要整窗黑色。
- 16px 卡片圆角、8px 小控件圆角；卡片边线 #EEDFD1，页面边距 20px、卡片间距 12px。中文统一 Microsoft YaHei UI 或现有中文字体；不使用装饰箭头/表情字体。装饰用简单矢量弧线/爪印，勿影响点击区或动画帧。
- 顶部左侧小爪印图形 + “麦麦小窝”，下一行轻文案“陪你把今天慢慢做好”；右侧轻按钮“刷新额度”。导航四个圆润标签：小窝 / 会话 / 麦当劳 / 设置。
- 首页第一块双角色陪伴卡：实际当前角色透明预览、名称、当前真实任务状态；两个互斥角色按钮“麦麦”“DeepSeek 娘”，现选用对应橘/蓝底。预览用真实素材，勿用通用鲸鱼或 AI 替代指定来源；角色切换后立即更新名/预览/选中态。
- 第二块“账号剩余额度”标题。订阅数据每个 provider 一个紧凑行：圆形 provider 字母/矢量徽记、名称、每个窗口独立的小进度条、已用百分比、剩余百分比、重置倒计时。进度条表达已用，剩余文字同口径，颜色按用量提高；不要把全部 provider 拼成一个总余额。Codex session/weekly 若只有weekly就只显示周窗口；Cursor 两个 bucket 在同一卡分两行。
- 失败/未知行保留位置：显示“刷新失败 / 尚无可读取额度”，不画已用0%的空条；有上次成功值则弱化展示并写“上次快照，已过时”。显示来源“Orca 账号缓存”与更新时间，可折叠详细原因；异常文字纯文本且安全。
- 金额余额另一个小卡“DeepSeek API 余额”：币种和精确金额；有赠送/充值数据则单独两小行。不配置时“未配置余额查询密钥”+跳到设置按钮，勿承诺充值上限或给金额画假百分比。
- 首页最后轻量陪伴操作（摸摸、休息/唤醒、闲逛）保持原行为；会话页保留任务进度/上下文/本机历史token用量，明确“本机日志累计”；麦当劳功能与确认动作保持；设置只展示必要 masked 凭据与高级折叠项。

## 设计与实现证据边界

这份是主轨设计决定，不是 Pixso 已生成截图。获得 file_key 后主轨用实际 Pixso 工具新增这次专用 frame，检查布局并截图，再与 C 的真实 Qt 对照。演示设计数据必须标注“设计示意”，产品只能呈现实际 source 快照/未知状态。C 可以按本规格继续原生实现与禁网络验证，最终是否完成 Pixso 输出据实记录。
