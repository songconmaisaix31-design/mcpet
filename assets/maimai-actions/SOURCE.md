# 麦麦新增动作

用户于 2026-10-12 提供两段 MP4 并要求加入项目：

- `桌宠炸薯条循环动画制作 (1).mp4` → `frying`（炸薯条，手动循环）。
- `1-2秒换装转场视频制作.mp4` → `outfit`（换装，播放一次）。

两段实际均为 720×720、24fps、约 10.08 秒的 H.264 视频，包含音轨和实色背景，
没有透明通道。文件名里的“1-2秒”不是整段视频时长。本次保留整段动作，
以 12.5fps 等间隔采样，每段 127 帧，Qt 每帧 80ms，播放约 10.16 秒。
不播放原音轨，不需要运行时视频解码器。

离线转换估计左右边缘的纵向灰色背景渐变，去掉与画布边界连通的中性背景和地面阴影，
保留封闭区域的白色衣物，再轻微柔化边缘。此为基于实色视频的抠图，透明光效与边缘
只能近似恢复；换装主要蓝色光环保留，白色背景光束未保留为背景。未宣称与原视频
逐像素相同。所有帧统一将完整 720×720 画布缩至 192×192，不逐帧裁边或移动人物。

复用项目既有 `AnimationSheet` 分页格式：每页 12 帧、2304×192 RGBA PNG。
播放器仅加载当前页和两张近期缩放帧；原麦麦图集、默认动作和静态预览继续使用原素材。
这两段新动作中的形象来自用户视频，因此动作切入/结束时与原占位图集形象有差异。
本次未替换其他动作，也未新增第三个角色。

当前 Agent 入口通过 `mcpet_pet` 选择动作，并提供 `frying.gif` / `outfit.gif`
资源给宿主读取；编码后相同帧合并为各 126 帧，总时长仍为 10.16 秒。
导出脚本为 `scripts/build_agent_animations.py`，原 PNG 页保持。GIF 内嵌播放能力
取决于宿主，未创建单独播放窗口；验证见 [Agent 接入记录](../../docs/AGENT-HOST-VALIDATION.md)。

以下交互描述属于旧桌面兼容入口：小窝首页“陪伴控制”及桌宠右键/托盘菜单提供炸薯条、换装和停止动作。
换装结束恢复原通知/后台动作，后台观测继续更新。拖拽、摸摸、休息或成功切换角色
结束手动动作；动作不跨应用重启保存。DeepSeek 娘下按钮禁用、菜单不显示这两项。
显示动作不等于真实做饭、购买或 Agent 任务完成，不触发任何账号、MCP 或模型请求。

复现（仅转换工具需要 Pillow、numpy、opencv-python 和 FFmpeg；应用依赖不变）：

```powershell
python scripts/import_maimai_actions.py FRIES_MP4 OUTFIT_MP4 FFMPEG_EXE
```
