# 新版视频：余额样板

事实源：用户的《McPet 发布视频 · 行为驱动视频生成任务书（v2）》及“用 aliyun cli 的语音，没有对应动作的用气泡代替”。

本阶段只交付 `Pet.worry(Balance)`。单 Agent 在 `videos/mcpet-reel/` 内实现独立的 Remotion 预览，不改变 Python 应用技术栈。安装技能锁与忽略规则属于必要配套。

1. 安装 Remotion 技能，阅读连续性、字体、音频与动态时长规则及参考项目。
2. 拉起 Studio，再实现原创几何鲸鱼娘、余额滚落、衰减抖动及气泡；Aliyun CLI 合成龙华配音，代码合成音效。
3. 用物理与语义完成条件测量样板，生成 `timeline.json`；检查确定性、结束姿态、安全区、字体与音频。
4. 提交并推送本阶段源码，保持 Studio 打开，输出验收报告，等待用户确认画风与声音。

后续七个行为、全片 40–60 秒调节、相邻行为逐帧连续性、成片渲染及 `.claude/skills/mcpet-reel` 收尾均在样板确认后推进。当前不执行 MP4 渲染。

假设与差异：原提示词库地址无法访问，采用同一作者的 `opus-video-prompts` 阅读长提示词组织方式；不复制参考实现。页脚采用最新任务书明确要求的原句。没有对应角色动作的业务表达由气泡承担。
