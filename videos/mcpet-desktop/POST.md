上周凌晨改 bug，一抬头十二点半，外卖早凉透了。顺手看了眼 DeepSeek 余额：4 块 3。

那一刻我决定，得有个人管管我。

于是做了个开源小项目 McPet：一只 DeepSeek 鲸鱼娘桌宠。余额要没了她比我先慌，Agent 跑任务她全程陪跑，中午十二点自动换上麦当劳工装喊我吃饭，顺手把券全领了。今天中午的板烧买一送一，就是她盯着我吃完的。

说个真实感受：她的“慌张”动画我调到凌晨两点。但看到她因为我只剩 4 块 3 急得跳脚那一刻，突然觉得挺值的——好像很久没有谁，会为这种小事替我着急了。

开源在 GitHub，搜 mcpet。正在参加 1024 程序员节大赛，排名只看 Star，帮我点一颗，就当请她吃顿饭

想问问大家：你有多久没好好吃一顿午饭了？评论区顺便晒晒你的 API 余额还剩多少，看谁才是真·麦门信徒
